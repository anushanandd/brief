# Decisions

Each record says why a choice was made, so it isn't reversed by someone who doesn't know. A record is dated and stays as written; when a choice changes, a new record replaces the old one and says so, and the old one is marked superseded.

Write one when you choose between real alternatives and the reason can't be read from the code. Keep it to a page: the context, the decision, and what follows from it. A decision whose reason is personal goes in `notes/decisions/`, which stays on this Mac.
